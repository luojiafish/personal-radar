# 热点维与官方维发现规则

使用当前公开主流平台建立近期热度，再用官方原始来源核对事实。Bilibili、Douyin 作为默认候选，但应根据主题选择更合适的平台。

1. 用关注对象全名搜索，再搭配一个启用关键词复查；只使用可归属到具体作者、账号或机构的原始链接。
2. 记录可见发布日期、互动量或平台趋势标记等热度信号；没有可见信号时写“热度无法独立核实”。
3. 热点维可包含公众讨论与创作者观点，但必须标成事实、观点或不确定信息。
4. 官方维优先官网、正式公告、权威机构和可确认的官方账号；不得用媒体转述替代可访问的官方原文。
5. 记录登录、验证、索引陈旧和日期不可见等限制，并继续读取其他安全公开来源。

Recommend a channel only when it shows stable attribution, repeated target relevance, or distinctive value missing from existing curated routes. Never promote a platform home page, generic search result, or single viral item solely because it ranks highly.
