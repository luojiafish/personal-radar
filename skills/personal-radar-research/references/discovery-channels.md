# Mainstream discovery rules

Use this pass after curated-channel research.

1. Search major video and social platforms for the exact target name, then repeat with one high-value enabled keyword.
2. Prefer official accounts, consistently focused creators, recurring columns, and recent items with attributable links.
3. Use authoritative public sources to establish the mainstream framing and cross-check material claims.
4. Record login, verification, indexing, and freshness limitations.

Recommend a channel only when it shows stable attribution, repeated target relevance, or distinctive value missing from existing curated routes. Never promote a platform home page, generic search result, or single viral item solely because it ranks highly.
